# UrbanFlow AI — SIH 2026

**GitHub Pages-ready static demo** of the UrbanFlow city transport/logistics intelligence dashboard.

## GitHub Pages
Upload this repository with `index.html` in the root, then enable:
**Settings → Pages → Deploy from branch → main → /(root)**.

The public demo runs in static mode and does not require the FastAPI backend.

### Demo login
`admin@urbanflow.local` / `admin123`

### Judge flow
**Detect → Predict → Decide → Act → Measure**

### Full-stack local version
The original FastAPI backend remains in `backend/`. For local development, use `start.bat` and open `http://127.0.0.1:8000`.

### Data note
Traffic, GPS, fleet, capacity and impact figures in the demo are simulated prototype values. They should not be presented as live Bengaluru measurements.

# UrbanFlow AI — GitHub Pages

This copy is prepared for static hosting on GitHub Pages.

## Publish
1. Create a **public** GitHub repository, e.g. `UrbanFlow-SIH`.
2. Upload everything in this folder. Keep `index.html` in the repository root.
3. GitHub → **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Branch: `main`; folder: `/ (root)`; Save.
6. Open the URL GitHub provides, usually:
   `https://YOUR-USERNAME.github.io/UrbanFlow-SIH/`
